# 42 Piscine - C Exercises

This repository contains my solutions to the C Piscine at 42 School.

⚠️ Note: The original exercise descriptions are not included due to copyright restrictions.

## Structure

Each folder (C00 to C06) corresponds to a set of exercises focused on specific concepts:

- C00: Basic syntax, output functions
- C01: Pointers and memory basics
- C02: Strings and arrays
- C03: String manipulation
- C04: More string functions
- C06: Program arguments

## Goals

- Practice low-level programming in C
- Understand memory and pointers
- Build functions from scratch (no standard library)
